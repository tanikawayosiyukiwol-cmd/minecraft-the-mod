⌨️ 便利コマンド一覧

シングルプレイやサーバー管理で役立つ、Java版の基本コマンドをまとめました。

注意： ほとんどのコマンドは「チート（ズル）」を有効にしたワールド、またはOP（管理者）権限が必要です。ワールド作成時に「チートを許可する」をONにしてください。

ゲームモード・難易度

コマンド効果
/gamemode creativeクリエイティブモードに切り替え
/gamemode survivalサバイバルモードに切り替え
/difficulty peaceful難易度をピースフルに（敵Mobが出なくなる）

時間・天気

コマンド効果
/time set day昼にする
/time set night夜にする
/weather clear天気を晴れにする
/weather rain雨を降らせる

移動・アイテム

コマンド効果
/tp [プレイヤー名]指定したプレイヤーの場所にテレポート
/tp [X] [Y] [Z]指定した座標にテレポート
/give @s [アイテムID] [個数]自分にアイテムを与える

ゲームルール（便利設定）

コマンド効果
/gamerule keepInventory true死んでもアイテムを落とさなくなる
/gamerule doDaylightCycle false時間の経過を止める（昼夜固定）
/gamerule doMobSpawning falseMobが自然湧きしなくなる

その他

コマンド効果
/effect give @s [効果名] [秒数] [強さ]自分にステータス効果を付与
/summon [Mob名]指定したMobを出現させる
/fill [座標1] [座標2] [ブロックID]範囲を指定してブロックで埋める
