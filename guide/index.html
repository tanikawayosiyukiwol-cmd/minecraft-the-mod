🔰 初心者向け入門ガイド

Minecraftを始めたばかりの方向けに、最初の数日でやるべきことをまとめました。

1日目：まず木を集める

  1. 木を素手で殴って「原木」を集める（最低5〜6個）
  2. クラフト画面で原木から「木材」を作る
  3. 木材4個で「作業台」を作成し、地面に設置する
  4. 作業台で「木のツルハシ」「木の斧」「木の剣」を作る

2日目までにやること：石器化

  1. 木のツルハシで丸石を掘る
  2. 丸石でツルハシ・斧・剣・シャベルを作り直す（耐久・速度が上がる）
  3. 丸石8個+作業台の要領で「かまど」を作成
  4. 鉄鉱石を見つけたら、かまどで木炭または石炭を燃料に精錬する

夜が来る前に：シェルターを作る

Minecraftでは夜になるとゾンビなどの敵mobが出現します。日が暮れる前に、穴を掘って入口をふさぐだけでも十分な避難場所になります。ベッドがあれば、寝ることで夜をスキップできます。

序盤の優先目標

  • 鉄装備（剣・防具一式）を整える
  • 食料を確保する（動物を狩る、または農業を始める）
  • 村を見つけたら、取引で便利なアイテムを手に入れる
  • ダイヤモンドを見つけたら、エンチャントテーブル用の黒曜石も集めておく

次のステップ

装備が整ってきたら、ネザー座標計算機を使って効率よく遠くまで移動したり、便利コマンド一覧でシングルプレイをより快適にする設定を試してみてください。
